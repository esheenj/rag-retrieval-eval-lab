# Contributing to RAG Retrieval Evaluation Lab

We welcome original synthetic retrieval fixtures, reproducible ranking counterexamples, unit tests, explainers, keyboard-access improvements and bounded deterministic metrics.

1. Create a focused issue with invented relevance document IDs, ranking lists and expected metrics.
2. Work on a feature branch; add a negative test before changing the evaluator.
3. Run npm test, npm run check:site and npm run demo.
4. Submit a PR with source evidence and remaining metric limitations.

No private corpora, customer prompts, generated confidential text, credentials, employer IP, trading/exchange code, real service APIs or paid infrastructure. The project is educational and remains offline.
